# TurismohnBeatriz

Guía estática de lugares turísticos de Honduras (HTML + CSS + JS).

## Cómo verla en el navegador

Abre `index.html` con doble clic, o sirve la carpeta:

```bash
cd ~/Documents/cursor_projects/TurismohnBeatriz
python3 -m http.server 47231
```

Luego entra a `http://127.0.0.1:47231/`.

Fotos en `assets/`. Cayos Cochinos es de dominio público (Elmer Claros, Wikimedia Commons, archivo «Cayos cochinos (29)»). Lago de Yojoa es de Carlos Arita, CC BY-SA 3.0 (Wikimedia Commons).
